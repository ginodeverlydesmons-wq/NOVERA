# NOVERA — Streetwear

Boutique e-commerce française de streetwear.

## Stack
- Next.js (App Router)
- JavaScript
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000.

> Le catalogue contient des produits de démonstration. Aucun paiement réel ni stock réel n'est activé dans cette première version.
